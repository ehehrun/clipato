# Clipato

**简体中文** | [English](README.md)

Clipato 是一款适用于 **macOS 14 及以上版本**的截图、贴图、录屏和图片整理工具。你可以快速截取画面、将图片固定在桌面作参考，也可以整理素材、制作长图与拼图，或批量压缩、改尺寸和转换格式。

截图、录屏和素材保存在本机。应用常驻菜单栏，无需一直打开控制台。

![Clipato 控制台与示例图片](assets/clipato-console.webp)

*当前 Clipato 真实界面，图片为演示素材。*

## 功能一览

| 功能 | 可以做什么 |
| --- | --- |
| 截图与标注 | 截取区域或当前屏幕，添加矩形、箭头、画笔、文字和马赛克 |
| 固定贴图 | 将图片置顶显示，拖动位置、缩放大小，方便对照与参考 |
| 连续截图与拼图 | 连续截取页面，拼接长图，或使用网格、自由拼图整理多张图片 |
| 录屏 | 连续录制 MP4，或仅保存画面发生变化的关键帧 |
| 保管箱与收藏夹 | 搜索、筛选、排序、预览和归类图片及录屏 |
| 图像处理 | 批量压缩、调整尺寸、转换格式、命名，以及单张图片宫格切图 |
| 重复与相似检测 | 找出重复文件，以及画质不同或局部内容相似的图片 |
| AI 协作 | 为 Codex 或 Claude Code 安装 Clipato Skill，也可通过 MCP 接入其他兼容客户端 |

## 快速开始

请按 Mac 芯片选择 DMG：**Apple Silicon（M 系列芯片）下载 `arm64`，Intel 芯片下载 `x86_64`**。不确定时，可在 **苹果菜单 → 关于本机**中查看。两个版本均要求 **macOS 14 或以上**。

从 DMG 将完整的 `Clipato.app` 复制到任意本地文件夹即可运行；`Applications` 是快捷安装入口。移动后请从新位置重新打开 App，重新安装 Skill，并更新已有外部 MCP / CLI 配置中的路径。

1. 打开 `Clipato.app`。应用图标出现在 macOS 菜单栏中，不会自动弹出控制台。
2. 首次截图或录屏时，按系统提示授予屏幕录制权限；如果 macOS 要求重新打开应用，请退出后再启动。
3. 按 `F1`，拖动选出一个区域，按需标注，再点击复制、保存或贴图。普通模式下，完成的截图会自动进入保管箱。
4. 按 `F2`，将最近记录的图片固定到桌面。
5. 点击菜单栏图标，选择 **控制台**，查看截图、录屏和收藏夹。

macOS 的权限页面可能名为 **屏幕与系统音频录制**，这是系统的分类名称。Clipato 实际仅采集画面，不采集系统音频，也不申请麦克风权限。

### 默认快捷键

| 快捷键 | 操作 |
| --- | --- |
| `F1` | 截取区域 |
| `F2` | 贴出最近图片 |
| `F3` | 开始录屏；录制时再次按下可停止并保存 |
| `F4` | 固定区域连续截图；再次按下截取下一张 |
| `F5` | 切换贴图鼠标穿透 |

如果 Mac 将功能键用于亮度或音量，请尝试同时按住 `Fn` / `🌐`，或在 Clipato 的 **快捷键设置**中改用其他组合键。

关闭控制台后，Clipato 仍会在菜单栏运行。要完全退出，请选择菜单中的 **退出 Clipato**。

## 截图与贴图

### 截取画面

1. 将鼠标移到需要截图的显示器，按 `F1`，或选择菜单 **截取区域**。
2. 框选前，鼠标旁显示像素放大镜和色值。按 `C` 复制色值，按 `Tab` 在 HEX、RGB、HSL 间切换。复制后可继续框选，或按 `Esc` 退出。
3. 拖动创建选框，取色信息随即隐藏。松手后可拖动选框内部移动位置，也可拖动边缘手柄调整大小。
4. 使用浮动工具条添加标注，或直接完成截图。
5. 选择复制、保存或贴图。非文字输入状态下，按 `Enter` 可完成并复制；按 `Esc` 取消。

色值来自截图原始像素，使用 sRGB。默认格式为 HEX，可在 **系统设置 → 截图与取色 → 默认色值格式**中改为 HEX、RGB 或 HSL。`Tab` 切换仅对当前截图生效，不修改默认设置。

全屏十字线默认开启，可在 **系统设置 → 截图与取色 → 显示全屏十字线**中关闭或重新开启。

选择菜单 **截取当前屏幕**，可以直接截取鼠标所在的整块显示器，并进入标注操作。

每次截图限定在一块显示器内。要截取另一块显示器，请先将鼠标移过去，再启动截图。

### 添加标注

- **矩形、箭头、画笔**：突出重点区域、标明方向或自由绘制。
- **文字（T）**：点击图片输入文字，可调整颜色和字号。`Enter` 换行，`⌘Enter` 完成文字输入；完成后可拖动文字，双击重新编辑。
- **马赛克**：选择矩形覆盖或涂抹，并调整颗粒与笔刷大小。
- **修改标注**：选中文字或图形后按 `Delete` 删除；`⌘Z` 撤销，`⇧⌘Z` 重做。马赛克通过撤销、重做调整。

保管箱里的图片也可通过右键菜单进入标注。查看时的缩放不会改变图片的实际分辨率。

### 固定贴图

截图工具条的贴图操作会将图片固定在当前选区位置。也可以在保管箱中右键贴图，或按 `F2` 贴出最近记录的图片。

贴图窗口始终置顶：拖动可移动，滚轮可缩放，右键可复制，双击或按 `Esc` 可关闭。

按 `F5`，或选择状态栏菜单 **贴图鼠标穿透**，可让鼠标操作穿过全部贴图并作用于下方窗口。再次按下或取消菜单勾选即可恢复贴图操作；快捷键可在 **快捷键设置**中自定义。

首次使用或恢复默认快捷键时包含 `F5`。已有快捷键配置不会自动增加绑定，请在 **快捷键设置**中为此项指定按键。

## 连续截图与拼图

### 连续截图制作长图

适合网页、聊天记录、文档和分步骤操作画面。页面滚动和下一次截图均由你手动触发。

1. 按 `F4` 或选择菜单 **固定区域连续截图**，框选区域并确认，截取第一张。
2. 滚动页面，保留一部分共同内容，再按 `F4` 或点击浮动条的 **截一张**。
3. 重复操作，完成后点击 **完成长图**，进入拼图工作台的长图模式。
4. 检查自动拼接结果。需要时调整容错范围并重新点击 **自动拼接**，或直接拖动图片、调整接缝。
5. 选择拷贝或导出，按提示保存结果。

连续截图期间，可拖动浮动条的移动手柄调整选框位置。参考线记录第一次截图的位置，靠近时自动吸附；按住 `Option` 可临时关闭吸附，点击移动手柄后，还可用方向键微调，或回到第一次截图位置。

自动拼接需要共同的文字或图形。重复纹理、固定页头和动画可能影响对齐；结果不合适时，可使用 **撤销拼接**或手动调整。

### 网格与自由拼图

在保管箱中选中图片，点击 **Grid / 自由拼图**；在收藏夹中选中图片，点击 **拼图 · N 张**。选择 **长图拼接**则进入同一工作台的长图模式。

| 模式 | 使用方式 |
| --- | --- |
| 网格 | 指定行列、图片最大尺寸和间距，将图片排列到规则单元格中 |
| 自由拼 | 拖动、缩放、叠放图片，调整层级；也可开启一键拼自动排列 |
| 长图 | 自动对齐相邻截图，或手动调整图片位置与接缝 |

顶部缩略图可拖拽排序。预览支持缩放与适合窗口；查看倍率不会改变导出尺寸。关闭尚未保存的工作台时，应用会先请你确认。

## 录屏

录屏**不支持录音，不采集系统声音或麦克风**，主要用于回看画面和后续按帧截取图片。

### 选择录制方式

打开 **系统设置 → 录屏**，选择下一次录制使用的方式：

| 录制方式 | 适合场景 | 保存内容 |
| --- | --- | --- |
| 直接录 · MP4 | 记录连续画面，便于回看和后续按帧截图 | MP4 视频 |
| 关键帧 | 文档、课件、操作步骤等变化较少的画面 | 变化时保存的图片与时间轴，可导出 MP4 或 GIF |

**高级选项**默认收起，可调整帧率、最长边等参数。关键帧采样频率可选每秒 1、2、4 帧；变化阈值越低，越容易记录画面变化。

### 开始、暂停和结束

1. 按 `F3`，选择状态栏菜单 **区域录屏**，或点击录屏页面的 **开始录屏**。
2. 框选并调整录制范围，确认工具条上的录制方式，再点击开始。
3. 绿色边框标记录制区域。使用浮动条暂停、继续或停止；暂停时间不会计入成片。
4. 点击停止，或再次按 `F3`，完成保存。
5. 在控制台的 **录屏**页面查看结果，双击播放。

启动录制时，请先将鼠标移到目标显示器；录制开始后范围固定。

### 关键帧的播放与导出

在关键帧录制的导出菜单中，可选择：

- **MP4 / GIF**：按原来的停留时间播放各帧。
- **导出到保管箱**：按时间顺序将关键帧保存为独立图片，便于继续标注或拼图。

原始录制会保留。也可打开录制文件夹中的 `player.html` 离线播放；分享这种录制时，请复制整个文件夹。

## 保管箱与收藏夹

### 导入、查找与展示

在 **截图保管箱**顶部点击 **导入图片**，可导入 PNG、JPEG、HEIC 等 macOS 可读取的图片。具体格式以文件选择器及系统解码能力为准；导入会保留原文件名和原始文件内容。

保管箱、录屏和收藏夹均支持：

- 搜索、颜色标签筛选，以及按时间、文件大小或名称正序、倒序排列。
- **概览**：默认模式，以等大的方格展示缩略图，隐藏底部信息；悬停时查看收藏夹标记。
- **卡片**：按素材类型展示名称、文件大小等详细信息。

保管箱和录屏还提供 **全部 / 未归类**切换。未归类仅显示尚未加入任何收藏夹的素材；加入后会从该列表消失，全部列表中仍可找到。

### 选择与图片预览

| 操作 | 效果 |
| --- | --- |
| 单击 | 单选当前项 |
| `⌘` + 单击 | 添加或取消一项选择 |
| `⇧` + 单击 | 按当前排序选择从起点到末项的范围 |
| `⌘A` | 全选当前筛选结果；输入框内仍为选择文字 |
| 双击图片，或选中后按空格 | 打开图片预览 |
| 预览中按 `←` / `→` | 按当前列表顺序切换上一张、下一张图片 |
| 预览中按空格或 `Esc` | 关闭图片预览 |

图片预览支持缩放、100% 原始像素和适合窗口；系统支持时，可通过实况文本选中文字并复制。识别效果取决于图片内容、语言及系统支持情况。

### 使用收藏夹整理素材

点击侧栏 **收藏夹**旁的 `＋` 新建收藏夹。右键可重命名、选择文件夹颜色、调整顺序或删除。

将保管箱或录屏列表中的素材拖到侧栏收藏夹，即可加入；也可通过 **加入收藏夹**菜单批量归类。

收藏夹只有一级，不能互相嵌套。同一图片或录屏可以加入多个收藏夹，共用原文件，不会因归类而复制多份。

| 操作 | 对原文件的影响 |
| --- | --- |
| 加入收藏夹 | 增加归类关系，原文件保留 |
| 从收藏夹移除 | 取消当前归类，原文件及其他收藏夹归类保留 |
| 删除收藏夹 | 删除该收藏夹及其归类，原文件保留 |
| 移入废纸篓 | 移走原文件，并从所有相关收藏夹中移除 |

手动将已收藏素材移入废纸篓时，确认提示会说明涉及的收藏夹。文件可从系统废纸篓找回，已删除的归类关系需要重新整理。

## 图像处理

### 通用操作流程

压缩、调整尺寸、转换格式和宫格切图使用以下流程；批量命名和检测的操作见后文。

1. 进入侧栏 **图像处理**，选择需要的工具。
2. 在 **选择图片来源**中选择 **外部图片**或 **截图保管箱**。
3. 选好图片，设置参数并检查预览或输出计划。顶部面包屑和 **返回上一步**可用于调整选择。
4. 点击 **选择位置并导出…**，保存处理结果。

压缩、调整尺寸、格式转换和宫格切图会生成新文件，保留原件。**批量命名会直接修改所选文件名**，包括选择的外部文件；请先检查命名预览。

### 压缩、调整尺寸和转换格式

| 工具 | 操作要点 |
| --- | --- |
| 压缩图片 | 设置每张图片的目标体积；可允许必要时缩小尺寸，自动尝试在目标体积内保留画质 |
| 调整尺寸 | 选择一个或多个尺寸规格，支持保持比例、白底补齐、中心裁剪和自定义宽高 |
| 转换格式 | 输出 JPEG、PNG 或 WebP；JPEG 将透明区域填为白色，PNG / WebP 可保留透明度 |

这些处理可以在同一页面组合使用，例如先调整尺寸，再转换格式并压缩到目标大小。动图只处理首帧，不会保留动画。若无法达到目标体积或尺寸超出支持范围，应用会提示调整参数。

### 宫格切图

1. 选择一张图片，进入 **宫格切图**。
2. 先调整正方形裁切区域：拖动选框移动，拖动四角调整大小，或输入宽高。
3. 点击 **下一步：宫格设置**，选择 **4 宫格**或 **9 宫格**。
4. 设置单片尺寸和 **跳过间隙**，检查发布排列预览。
5. 导出后，按从左到右、从上到下的编号顺序发布。

**跳过间隙会裁掉原图中对应的像素**，用于补偿发布平台格子之间的空隙。因此，将切片直接无缝拼回，不能还原完整原图；不需要这项补偿时，将间隙设为 `0`。

### 批量命名

选择至少两张图片，或在录屏、收藏夹中选择至少两个完整视频，再进入 **批量命名**。所选内容必须为同一类型；关键帧录制档案不参与批量命名。

设置 **前缀、起始数字、递增步长、数字位数**，查看原名称与新名称的对照，确认后点击 **应用命名**。编号按当前列表顺序递增，扩展名保持不变。

例如，对 JPG 图片将前缀设为 `旅行_`、起始数字为 `1`、数字位数为 `3`，可生成 `旅行_001.jpg`、`旅行_002.jpg` 等名称。

### 查找重复文件与相似图片

进入 **图像处理 → 重复与相似检测**，选择检测方式和图片来源。要检测完整视频，请先在录屏或收藏夹中选中至少两个完整视频，再打开顶部的 **重复与相似检测**菜单（双层方框图标），选择 **查找重复文件**。

| 检测方式 | 适用内容 | 用途 |
| --- | --- | --- |
| 查找重复文件 | 图片、完整视频 | 找出文件内容完全相同的副本，即使文件名不同 |
| 查找相似图片 | 图片 | 查找画质、尺寸有差别，或存在局部包含关系的相似候选 |

检测结果不会自动删除。请逐组预览、选择不需要的内容，再点击 **移入废纸篓**并确认。相似结果是候选，需要你判断是否保留。

## 导出与分享

在保管箱或收藏夹中选择图片，打开 **导出 / 导出图片**菜单。批量导出按当前列表的显示顺序处理。

| 导出方式 | 结果与选项 |
| --- | --- |
| 图片 / PDF… | 逐张导出 PNG、JPEG，或合成每张图片一页的 PDF；JPEG / PDF 可调整质量 |
| ZIP 压缩包… | 将所选格式的文件打包，方便一次发送多张图片 |
| MP4 / GIF… | 将多张图片制作成视频或动图；提供 1、5、15 fps 快捷选项，高级选项可自定义 |

PNG 无损保存；JPEG / PDF 的 `100%` 表示最高编码质量。制作 MP4 / GIF 时，每张图片作为一帧，帧率越低停留越久，最低支持 `1 fps`。

需要 WebP 时，请使用 **图像处理 → 转换格式**。逐张图片输出遇到同名文件时不会直接覆盖；PDF、ZIP、MP4、GIF 等单文件导出，如选择已有文件，请按系统保存对话框确认是否替换。

## 设置与数据管理

### 语言、外观与快捷键

在 **语言与外观**中，可切换跟随系统、浅色或深色外观，选择配色并调整控制台字体大小。界面语言默认跟随系统，支持英语、简体中文、繁体中文、日语、韩语和藏语。

在 **快捷键设置**中点击录入框，按下新的快捷键；支持清除绑定和恢复默认。菜单 **禁用快捷键**可暂时停用全局快捷键，保留原有配置。

### 保存位置与容量

- **系统设置 → 文件保存位置**：分别设置截图与图片、录屏的保存位置。新位置用于后续内容，已有文件不会自动搬移。
- **系统设置 → 容量管理**：图片与录屏共用容量上限，默认不限。修改后点击 **保存设置**。
- **侧栏底部容量环图**：分别查看图片、录屏、缓存和访问日志占用；日志计入总占用，但不占用图片与录屏的容量上限。

自动清理默认关闭。开启后，只会将符合条件的最早图片移入废纸篓，**不会自动删除录屏**；默认保护已收藏、有颜色标签和最近 7 天的图片。

移入废纸篓后，只有清空系统废纸篓才会真正释放磁盘空间。

### 截图与录屏自动命名

在 **系统设置 → 自动命名**中，分别编辑截图和录屏规则，查看命名预览，再点击 **保存设置**。规则只作用于之后创建的截图和录屏，不修改已有文件、导入文件或命令行 / MCP 显式指定的输出名称。关键帧录屏使用录屏名称显示，内部帧序列保持原样。

| 写法 | 含义 |
| --- | --- |
| 固定文字 | 自定义前缀或分隔符，例如 `项目A_` |
| `{date}` | 日期，格式 `yyyy-MM-dd` |
| `{time}` | 时间，格式 `HH.mm.ss` |
| `{index}` | 递增编号，默认至少 3 位，如 `001` |
| `{index:4}` | 至少补齐 4 位；支持 1–12 位，编号超过指定宽度时自动扩展 |

默认截图规则为 `截图 {date} {time}_{index}`，例如 `截图 2026-10-20 14.30.00_001.png`；录屏默认前缀为 `录屏`。扩展名由输出格式自动添加，请勿在规则中填写。

截图和录屏分别连续编号，重启后接续，保存规则不会重置编号。预览不占用编号；操作取消或保存失败可能留下空号。

### 权限状态

在 **安全设置 → 权限 → 屏幕录制**查看 **已授权 / 未授权**状态。未授权时点击 **去授权**，已授权时点击 **管理权限**，都会打开 macOS 对应设置页面。截图与录屏共用此权限；Clipato 只采集画面，不采集系统音频或麦克风。

可使用安全设置中代表当前 App 的 `Clipato.app` 拖动卡片；若系统页面不接受拖入，点击屏幕录制列表的 **+**，选择当前 App 并打开开关。App 可以放在任意本地文件夹。返回 Clipato 时会刷新权限状态；若仍显示未授权，请完全退出后重新打开。

### 开机启动

**安全设置 → 开机启动**默认关闭。勾选后，登录 Mac 时会自动启动 Clipato，并常驻菜单栏。安装应用、启动应用或打开设置都不会添加登录项；应用只会在手动勾选后发起注册。

首次使用、尚未注册登录项时也可直接勾选；若注册失败，会显示系统返回的实际错误。

开关旁显示 **已开启 / 待允许 / 未开启**；待允许时需在系统登录项设置中批准。

若 macOS 要求批准，点击 **打开登录项设置**，在系统设置中允许 Clipato。关闭选项后会移除该登录项。

也可以手动添加：点击 **打开登录项设置**进入系统登录项页面，将设置页中可拖动的 `Clipato.app` 图标拖入 **登录时打开**列表；也可点击系统列表下方的 **+** 选择此 App。按钮和拖动源本身不会注册登录项，只有在系统设置中完成添加后才生效。

### 隐私模式

进入 **安全设置 → 隐私**，勾选 **开启隐私模式**，默认关闭。

开启后，截图不自动进入保管箱，也不记录新的最近贴图历史；已有素材和历史不会被清除。主动保存、导出以及录屏仍会写入相应位置。

隐私模式会关闭 **允许外部自动化调用**和 **启用 MCP 服务**两个开关，并禁止重新开启；退出隐私模式不会恢复它们。再次使用 Skills 或 CLI 时，需在 **AI 终端 → 自动化接入**中手动开启 **允许外部自动化调用**；MCP 还需单独开启服务。

### 清空操作历史与清理数据

两项操作的范围不同：

| 入口 | 清理范围 |
| --- | --- |
| 状态栏菜单 → 清空操作历史 | 清除最近贴图记录；不会删除素材、关闭已显示的贴图或清空系统剪贴板 |
| 系统设置底部 → 清理数据… | 在确认页分别勾选保管箱图片、录屏、收藏夹和操作历史，再执行清理 |

清理媒体会将文件移入系统废纸篓；仅勾选收藏夹不会删除媒体原件。收藏夹和操作历史清除后不能在应用内恢复，设置会保留。正在截图、录屏、编辑或处理图片时，请先完成当前操作，再清理数据。

### 检查更新

在 **系统设置 → 关于与更新**查看当前版本并点击 **检查更新**。

发现新版后，可阅读更新说明并点击 **前往下载**。检查仅在你主动点击时进行，不会自动安装新版。

每台 Mac 按本地自然日最多发起 **5 次 HTTP 更新请求**，午夜重置。失败请求、每个备用地址及 HTTPS 重定向均单独占用次数，重启应用不会重置。达到限额后，显示上次成功检查的结果和时间，包括「当前已是最新版本」的结果；失败不会覆盖成功缓存。没有成功缓存时，会明确提示明天再试。

## AI 协作

这是一项可选功能，应用内的截图、录屏和图片处理无需开启。Skills、MCP 客户端与命令行业务调用都需要 **允许外部自动化调用**总开关；MCP 另需 **启用 MCP 服务**。两个开关均默认关闭，隐私模式开启时无法启用。使用 Skills 或普通 CLI 命令时，可保持 MCP 服务关闭。

### 安装 Clipato Skill

1. 打开 **AI 终端 → 自动化接入**，勾选 **允许外部自动化调用**。
2. 在 **Skills**中点击 **安装到 Codex**或 **安装到 Claude Code**，无需配置 MCP 连接。
3. 在同一台 Mac 的对应客户端开启新对话，用自然语言请求截图、整理素材或处理图片。也可在 Codex 中输入 `$clipato`，或在 Claude Code 中输入 `/clipato` 显式使用。

| 操作 | Skill 保存位置 |
| --- | --- |
| 安装到 Codex | `~/.agents/skills/clipato` |
| 安装到 Claude Code | `~/.claude/skills/clipato` |
| 导出 Skill… | 所选位置下的 `clipato` 文件夹 |

目标目录已存在时，Clipato 会先确认是否替换其中全部内容；其他 Skill 和客户端配置不会更改。导出的 Skill 用于能够在这台 Mac 上执行命令的本机客户端，上传到 Claude 网页版不会获得本机访问能力。移动 `Clipato.app` 后，请从新位置打开，再重新安装或导出 Skill，更新程序路径。

例如：“将这些图片压缩到每张 500 KB，保留原图”，或“预览批量命名方案，确认前不要执行”。截图和录屏调用仍需要 macOS 屏幕录制权限。

### 通过 MCP 接入

1. 在 **AI 终端 → 自动化接入**开启 **允许外部自动化调用**。
2. 在 **AI 终端 → MCP 服务**勾选 **启用 MCP 服务**。即使旧版已允许外部调用，这个独立开关仍默认关闭。
3. 点击 **复制 MCP 配置**，添加到客户端并按其要求重新加载连接。只有两个开关都开启时才能复制配置；`clipato mcp` 命令也需要同时开启两项。

也可直接点击 **启用 MCP 服务**：总开关未开启时，Clipato 会先提示确认外部调用权限，确认后同时开启两项；取消不会更改权限。

关闭 **启用 MCP 服务**会断开 MCP 会话并取消其进行中的任务；总开关保持开启时，Skills、普通 CLI 调用及其进行中的任务不受影响。重新开启服务不会恢复旧 MCP 会话，需要客户端重新连接。

未开启 **允许外部自动化调用**时，所有 Skill、MCP 客户端和命令行业务调用均被禁止，包括此前连接的客户端。关闭总开关也会关闭 MCP 服务，撤销现有会话、取消全部进行中的自动化任务并安全收尾；已完成的写入不会撤回。重新开启总开关不会自动恢复 MCP 服务，按需单独开启并重新连接客户端。命令行帮助、版本信息、`permissions` 诊断和 `tools [NAME]` 能力定义在两个开关均关闭时仍可查看。

**允许自动化请求移入废纸篓**默认关闭。即使开启，每批移入废纸篓仍需你在 Clipato 中确认；不提供永久删除或一键清空全部数据的自动化工具。

MCP 与所有命令行调用的记录可在 **访问日志 → 查看日志**中查看，包含原始参数、执行结果和耗时。进程信息由系统读取，MCP 客户端名称与版本由客户端自报。日志不会读取图片文件内容，也不记录完整返回内容。

在 **AI 终端 → 访问日志**设置日志总容量上限，默认 **20 MB**，可填写 **1–1024 MB** 的整数并保存。当前日志与轮转文件共用该上限，超出后自动删除最旧日志文件。调小上限也会清理旧日志。

应用移动位置后，请重新安装 Skill，并重新复制 MCP 配置。命令行用户可在 **使用指南 → 复制命令行帮助命令**中获取当前安装位置的帮助命令。

## 常见问题

### 启动后为什么没有窗口？

Clipato 默认只在菜单栏运行。点击菜单栏图标，选择 **控制台**即可打开；关闭控制台不会退出应用。

### 截图或录屏提示权限不足怎么办？

在 **安全设置 → 权限 → 屏幕录制**查看状态并点击 **去授权**；也可在 **使用指南**中点击 **打开屏幕录制权限设置**。按 macOS 提示授权，返回 Clipato 后会刷新状态；若仍未授权，请完全退出并重新打开。通过 AI 客户端或终端调用时，请以系统实际提示的授权对象为准。

### F2 为什么没有反应？

没有最近贴图记录时，菜单 **贴出最近图片**会禁用，`F2` 不执行操作。清空历史或删除该记录对应的图片后，需再次完成截图、导入图片或主动贴图，才会产生新记录。隐私模式下，新截图不会更新记录。

### 大批量图片会一次加载全部原图吗？

列表按需加载缩略图；打开预览、编辑或执行处理时再读取相应图片。批量处理大图时，适当降低输出尺寸可减少内存占用。

### 为什么转换格式后文件反而变大？

格式、画面内容和编码质量都会影响体积。PNG 保留无损像素，不一定比 JPEG 小；需要控制上传大小时，请使用 **压缩图片**设置目标体积。

### 当前有哪些使用限制？

- 录屏不支持录音，截图和录屏选区不跨越多块显示器。
- 动图的图像处理与相似检测只使用首帧。
- 实况文本取决于系统支持情况；尚不提供整个保管箱的文字内容检索。
- 图片相似检测不能替代人工判断；复杂画面的长图拼接可能需要手动调整。
