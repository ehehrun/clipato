Clipato 隐私说明

发布前草案 · 按 2026 年 10 月 23 日的当前代码核对

本说明可在应用内离线阅读，目前是发行准备草案，尚未发布为公开隐私政策链接。公开发行前，需要确认运营者及隐私联系渠道，核实更新托管方的访问日志做法，并将定稿发布到公开 HTTPS 地址。App Store 隐私信息还需按最终发行包及实际服务核对。

1. 屏幕内容与本机处理

Clipato 在用户通过应用或已授权的本机自动化调用启动操作时截图或录屏，需要 macOS 屏幕录制权限。其他应用显示的个人或机密信息可能出现在画面中，请谨慎选择截取范围。

Clipato 仅采集画面，不采集系统音频或麦克风，不请求麦克风或相机权限。录屏期间显示录制状态和操作控件。

图片、关键帧、视频、缩略图、重复和相似图片比较以及实况文本选字在 Mac 上处理。当前应用没有内置账号服务、广告 SDK、统计分析 SDK，也不会自动将屏幕内容、保管箱文件或访问日志上传给开发者。其他应用、系统服务或用户选择的客户端如何分享内容，不受此说明控制。

2. 保存文件、历史与剪贴板

截图通常自动进入本机保管箱。录屏、导出文件、收藏夹、名称、标签、媒体信息、缩略图和最近贴图历史保存在本机，可自行选择其他保存位置。现有默认保管箱保留 FrameVault 文件夹名称以兼容已有数据，并不代表使用另一个服务。

用户主动复制图片、色值、命令或配置时，内容写入 macOS 剪贴板。其他应用、剪贴板管理器及系统剪贴板功能可能按其设置读取或保留内容，Clipato 无法清除这些副本。

媒体与日志是普通本机文件，Clipato 不另外加密，由文件权限及 Mac 的存储保护机制提供保护。导出到共享目录、同步目录或备份中的文件，遵循相应位置的访问和保留规则。

3. 可选的外部自动化

独立发行版中的 Skills、CLI 业务调用和 MCP 均为可选能力，默认关闭。外部自动化总开关允许本机业务调用，MCP 还需要单独开启服务开关。MCP 使用本机标准输入和输出，Clipato 不为此开放网络监听端口。

开启后，本机客户端可以请求工具提供的截图、保管箱访问和图像处理能力。工具结果、路径及请求的内容会返回给该客户端。AI 助手等客户端可能再将信息发送给自己的服务。启用或调用前，请查看客户端权限及其隐私政策。Clipato 无法控制客户端的存储、云端处理及其收到副本后的删除行为。

关闭外部自动化总开关会撤销已有授权、关闭 MCP 并取消进行中的外部任务；仅关闭 MCP 不影响仍获授权的 Skills 和普通 CLI 调用。撤销授权不会撤回已经完成的写入。自动化移入废纸篓需要额外开关，并逐批确认。调用进程信息仅供诊断，不等于验证客户端身份，也不能防范以用户本人权限运行的恶意代码。

某些发行渠道可能不提供外部自动化，具体以当前安装版本中的控件和能力为准。

4. 本机访问日志

提供外部自动化的版本会记录 MCP 和 CLI 调用，包括原始命令参数或 JSON 参数、时间、状态、耗时、相关素材引用及能读取的调用进程信息。进程信息可能包括可执行文件和应用路径、进程名称、Bundle ID 及父进程。MCP 客户端名称和版本由客户端自行报告。日志不读取图片文件内容，也不记录完整工具返回值，但调用方传入的参数仍可能含有敏感文字、文件名或路径。

CLI 启动尝试、帮助、权限诊断、无效命令及被拒绝的调用也可能被记录。关闭自动化或开启隐私模式不会删除已有日志，也不会禁止所有拒绝调用日志。Clipato 不上传访问日志。日志总容量默认 20 MB，可设为 1–1024 MB。当前文件及最多三个轮转文件共用此上限，在日志活动或调整上限时按需移除最旧文件。

日志位置可在「AI 终端 → 访问日志」查看，保管箱数据清理不会删除这些日志。如需手动移除，请先停止可能继续写日志的外部客户端并退出 Clipato，再删除界面所示位置的当前及轮转日志文件。之后的 CLI 尝试或打开日志设置仍可能创建新日志。

5. 更新检查与网络请求

独立发行版在用户点击「检查更新」时访问内置的 HTTPS 更新源，请求中不包含截图、保管箱内容、访问日志、设备标识或自定义用户标识。更新连接不使用 Cookie 存储、凭据存储或响应缓存。服务器及托管方仍可看到来源 IP 和普通 HTTPS 请求信息，其访问日志保留方式需在本说明定稿前核实。

每个本地日历日最多发送五次实际更新 HTTP 请求，失败、镜像及重定向均计数。请求次数、日期和最近一次成功的更新清单保存在本机，达到上限后展示缓存结果。点击下载会在浏览器中打开版本地址，后续适用浏览器及目标网站的数据处理方式。App Store 版本通过 App Store 更新，不使用此外部更新机制。

6. 隐私模式与删除

隐私模式禁止截图自动进入保管箱，也不增加最近贴图历史；同时关闭外部自动化与 MCP。退出隐私模式后，需要手动重新开启调用权限。隐私模式不删除已有文件和日志，不阻止用户主动录屏或导出，不清空系统剪贴板，也不保证不会产生临时文件。它不是安全擦除功能，也不是全系统网络隐私控制。

「系统设置 → 数据清理」可选择保管箱图片、录屏、收藏夹和操作历史。图片和录屏移入系统废纸篓，并移除相应收藏关系和最近贴图记录；收藏夹和历史无法在应用内恢复。清理也会清空应用缩略图，但保留设置、更新信息及访问日志。独立导出的副本、导入前的原文件、备份及其他应用持有的副本不会删除。废纸篓中的文件需按 macOS 规则清空后才会移除。

用户可随时在 macOS 系统设置撤销屏幕录制权限、关闭登录启动、关闭外部自动化，并管理已保存的文件。当前版本没有 Clipato 账号，也不要求注册账号。

7. 说明变更与隐私联系

Clipato 的数据处理或服务发生变化时，应同步更新本说明。将此草案用于公开发行前，必须补齐运营者身份、隐私联系渠道、公开政策地址，以及核实后的托管保留条款。本草案尚未配置联系地址或已发布链接。
